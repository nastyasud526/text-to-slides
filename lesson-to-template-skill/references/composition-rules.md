# Composition selection

Use an explicit author format first, then the template's own comment or speaker note. Select only a composition already registered in the current catalog.

When the source has no format, classify its teaching purpose: speaker-labelled exchange suggests a dialogue template; equal independent points suggest cards or columns; comparison suggests a contrast template; a concrete incident plus a conclusion suggests a case template; a dense explanation suggests the available title-and-text template.

If no exact composition fits, adapt the source to the closest existing composition before requesting a new template. Do not invent a layout ID from an item count. Preserve approved wording unless the user has explicitly accepted an editorial adaptation.
