# Каталог подготовленной библиотеки

Контракт подготовленного каталога хранится в `../../lesson-to-template/references/catalog-schema.md`, потому что навык подготовки создаёт тот же артефакт, который затем использует навык сборки урока. Прочитай этот файл до создания или изменения полей каталога.

При подготовке библиотеки считай заметки PowerPoint устойчивым физическим идентификатором и авторским описанием дизайна. `catalog.json` соединяет два уровня: поддерживаемый вручную семантический контекст (`groups`, `compositions`, описание, пример и смысловые поля) и автоматически обновляемый физический реестр `slides`. Обновляй числовые значения `sourceSlide` при каждом изменении порядка слайдов в библиотеке; эти значения не участвуют в выборе композиции.
