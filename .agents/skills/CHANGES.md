## Что не сделано и требует твоего решения

- В `catalog.json` стоит добавить каждой композиции `when_to_choose` и `not_when` одной фразой; `catalog_planner_view.mjs` их подхватит.
- Переименование полей (`text.key-idea.intro`, `thesis.example.illustration.definition/explanation`) я не трогал: это тянет за собой библиотеку PPTX.

## Как измерить эффект

1. `python3 scripts/extract_docx_blocks.py курс.docx source.json`
2. Прогнать `plan` для урока, например 1.4.
3. `python3 scripts/eval_plan.py разметка_шаблонов.csv <run>/lesson-plan.json`

Базовая точка для сравнения: чисто эвристическая разметка без чтения дала на уроке 1.4 точность 46% (по семействам 57%), главная путаница «цепочка → intro.body.conclusion» (6 из 28 слайдов).
