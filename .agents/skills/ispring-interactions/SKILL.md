# iSpring-интерактивности в презентации курса

## Результат

Навык заменяет технические слайды `staging.interaction` в уже собранной презентации на реальные iSpring-элементы из комплекта курса. Он сохраняет полный исходный текст, создаёт отдельные `.quiz` и `.visuals` для каждого элемента и проверяет связи PPTX с ресурсами.

## Вход

Перед запуском прочитай [контракт интерактивностей](references/interaction-spec.md). Используй только пути из секции `ispring_interactions` текущего `course.yaml`. Комплект PPTX и его одноимённая папка ресурсов являются единым шаблоном: не редактируй их и не подставляй ресурс из другого курса.

Входной `lesson-plan.json` должен хранить явный `interactionSpec`, подготовленный смысловым исполнителем. Этот навык является техническим рендерером: не перечитывай DOCX, не выделяй механику из `sourceText` и не исправляй неоднозначную заявку по догадке. Если `interactionSpec` отсутствует или не проходит контракт, оставь слайд `staging.interaction` и запиши его в `ispring-unresolved.json`.

## Поддерживаемые механики

- `quiz`: одиночный выбор, множественный выбор и сопоставление. Один блок теста может содержать несколько вопросов и соответствует одному PowerPoint-слайду.
- `steps`: последовательность раскрывающихся шагов.
- `tabs`: набор раскрывающихся вкладок.

Не меняй механику по догадке. Сортировка не поддерживается. Флип-карточки, маркированные изображения, ветвления, свободный ввод, карта и другие отсутствующие в реестре механики остаются на `staging.interaction`; внеси их в отчёт с исходным номером слайда и причиной.

## Сборка и проверка

После обычной сборки PPTX запусти `scripts/render_ispring_interactions.py`, затем `scripts/verify_ispring_output.py`. Используй Python, возвращённый `load_workspace_dependencies`. Оба скрипта пишут только в новую папку запуска и не перезаписывают существующий результат.

Готовый результат требует успешной структурной проверки, открытия в PowerPoint без диалога восстановления и контрольной публикации iSpring в SCORM. Если один из этих пунктов не пройден, не выдавай презентацию как готовую.
