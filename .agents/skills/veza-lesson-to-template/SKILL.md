# Сборка урока ВЕЗА по шаблонам

Это репозиторный входной навык для сборки презентаций уроков текущего курса ВЕЗА.

До любых действий по задаче полностью прочитай `../../../lesson-to-template-skill/SKILL.md` и следуй ему как основному процессу. Все относительные пути из этого процесса разрешай от корня репозитория, кроме ссылок, которые явно заданы относительно папки основного навыка.

Используй только ресурсы текущего курса:

- выбранный пользователем исходный текст урока из этого репозитория;
- `Производство дизайн шаблон — именованные поля.pptx` как подготовленную библиотеку шаблонов;
- `template-review/catalog.json` как подготовленный семантический каталог;
- `veza-dialogue-scenes` и референсы персонажей ВЕЗА для диалоговых сцен.

Не заменяй этот маршрут универсальным процессом проверки шаблонов из навыка `Presentations`. Не проверяй и не рендери всю библиотеку, не создавай монтаж шаблонов, не запускай `inspect_template_deck.mjs` и `unzip`. Во время сборки урока библиотеку проверяет только структурный preflight из основного процесса.

Этот входной навык относится только к текущему курсу. Не используй его библиотеку шаблонов, каталог, диалоговых персонажей, правила сцен и визуальные ресурсы для другого курса.
