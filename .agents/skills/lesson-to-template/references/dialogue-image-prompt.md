# Рабочий промпт диалоговой сцены

Используй эту справку только для слайда с диалогом. Все постоянные сведения о персонажах, окружении, стиле и композиции бери из раздела `dialogue_scenes` переданного `course.yaml`.

## Смысл сцены

Прочитай весь диалог и определи предмет разговора, действие, подходящую локацию и отношение каждого участника к ситуации. Оба персонажа являются активными участниками разговора. Подбери каждому соответствующие смыслу позу, жест и выражение лица; позы должны заметно различаться положением тела, поворотом корпуса и работой рук. Не используй одинаковые или зеркальные позы, совпадающие жесты, одинаковые выражения лица и ракурсы со спины.

Если исходник содержит `image_prompt`, сохрани указанное действие, место и предмет обсуждения. Удали из него требования нарисовать заголовок, реплики, облачка речи, подписи, метки, выноски, таблички и другой текст слайда.

## Карточка сцены

До генерации создай компактную карточку:

```json
{
  "slide_id": "<идентификатор слайда>",
  "topic": "<предмет разговора>",
  "location": "<идентификатор локации из course.yaml>",
  "discussion_object": null,
  "characters": [
    {
      "id": "<идентификатор персонажа>",
      "emotion": "<эмоция по смыслу его реплик>",
      "pose": "<поза>",
      "gesture": "<жест>",
      "gaze": "<направление взгляда>"
    }
  ]
}
```

Включи каждого участника диалога, его реплики и соответствующую реакцию на разговор. Используй только персонажей и локации, объявленные в `course.yaml`.

## Итоговый промпт

Пиши технический промпт на английском языке. Передай в нём:

- формат и стиль из `dialogue_scenes.style`;
- референс, внешность, одежду и сторону каждого персонажа;
- обязательный состав участников из `dialogue_scenes.required_characters`;
- действие и предмет разговора;
- описание выбранной локации и подходящие фоновые референсы;
- индивидуальные позы, жесты, выражения лица и направления взгляда;
- правило композиции из `dialogue_scenes.composition`;
- правила поз, направления взгляда, безопасности, допустимого текста и его размещения из конфигурации курса.

Заверши промпт явным требованием создать только персонажей и окружение. Не добавляй текст урока, заголовки, реплики, облачка речи, подписи, метки, выноски или таблички. Разрешай только постоянные маркировки, перечисленные в `dialogue_scenes.allowed_text`, и размещай их только согласно `dialogue_scenes.allowed_text_placement`.
