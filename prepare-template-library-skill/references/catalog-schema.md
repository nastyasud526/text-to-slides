# Каталог подготовленной библиотеки

Контракт подготовленного каталога хранится в `../../lesson-to-template-skill/references/catalog-schema.md`, потому что навык подготовки создаёт тот же артефакт, который затем использует навык сборки урока. Прочитай этот файл до создания или изменения полей каталога.

При подготовке библиотеки считай заметки PowerPoint устойчивым физическим идентификатором и авторским описанием дизайна, а `catalog.json` — автоматически формируемым техническим реестром с поддерживаемым вручную семантическим контекстом. Обновляй числовые значения `sourceSlide` при каждом изменении порядка слайдов в библиотеке.
